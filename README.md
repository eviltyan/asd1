# Текст лабораторной работы
**Задание 1**  
1.1 Для заданной вариантом последовательности чисел записать последовательность изменений при сортировке  
- методом выбора (пять итераций),  
- методом вставок (все итерации),  
- быстрой сортировкой (quicksort) в виде дерева разделений,  
- пирамидальной сортировкой(все итерации построения пирамиды на месте, пять итераций извлечения из вершины),  
- поразрядной сортировкой (результаты карманной сортировки (или сортировки подсчётом) по каждому разряду).  
  
1.2 Подготовить программные реализации алгоритмов сортировки целых чисел перечисленных в п.1.1, и протестировать на заданной вариантом последовательности чисел.  

**Задание 2**  
Провести тестирование реализованных алгоритмов на примере сортировки четырехзначных чисел. Проанализировать реальную вычислительную (временную) сложность алгоритмов, сравнить с теоретическими оценками.  
  
Рассмотреть три вида входных данных:   
- последовательность, упорядоченная в прямом порядке;  
- последовательность, упорядоченная в обратном порядке;  
- случайная последовательность.  
  
При генерации входных данных во всех случаях сделать возможным повторяющиеся значения. Количество сортируемых чисел не должно быть ограничено диапазоном значений, оно может на порядки превосходить диапазон значений.  
  
Результаты экспериментов представить в виде таблиц и графиков зависимости времени работы от длины последовательности. Рассмотреть не менее пяти точек для каждого эксперимента. Для каждого вида входных данных построить графики времени работы разных алгоритмов в одной системе координат. При необходимости (если слишком большой рост некоторых зависимостей делает другие неразличимыми) сравнить попарно или показать отдельно.
